# Turbo Relay on GameWave

Import the ZIP with index.html at its root. index.html and standalone.html are identical self-contained builds. Tap GO LIVE to start. SWITCH POWER transfers propulsion between the two couriers. After the first docks, BRAKE and GO control the remaining courier.

GameWave documentation rechecked November 9, 2026. https://rg975ojk5z.feishu.cn/wiki/MQg7wMknzieOkukxyWVc4UB0nDh

The game runs with or without window.neonlib. The first committed action starts the host round. A real clear, loss, or deliberate course change during an active round ends it. Pause and settings preserve the round. A restored checkpoint waits for RESUME RELAY to start the new host visit. Late discovery reports the active round once.

Local saves use turbo-relay-v1. The cloud envelope contains this game's versioned best scores, progression, preferences and reward flags. Local active positions and timing stay on the device. A recognized cloud profile merges best scores and reward flags. A known empty host save can initialize. Foreign data is left intact.

Optional current-player callbacks grant Lime paint after a positive onLike status or Pink paint after a direct onComment with a string project_id and string content, including empty image-only comments. These flags are durable and deduplicated. Registration requires code 0 and releases the returned unsubscribe on exit. The same paints are available from ordinary progression.

SDK tests use mocks. Actual GameWave App import, cloud account and social callbacks require a supported host for verification.
