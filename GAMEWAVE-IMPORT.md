# Turbo Relay 3D on GameWave

Import the ZIP with index.html at its root. index.html and standalone.html are identical self-contained WebGL builds. Tap the scene to start or switch power. Both-red waits and the final dock are automatic. The pause menu offers music and circuit replay.

GameWave SDK documentation rechecked November 9, 2026. https://rg975ojk5z.feishu.cn/wiki/MQg7wMknzieOkukxyWVc4UB0nDh

The game runs with or without window.neonlib. The first committed tap starts the host round. A true clear, loss, or explicit course change during active play ends it. Pausing and automatic waits preserve the current round. A restored checkpoint waits for RESUME RELAY before starting a new host visit. Late discovery reports an active committed round once.

The local key turbo-relay-v1 and the version-1 cloud profile are shared with the previous release of this same game. Active positions, score and timing are local. The recognized cloud envelope merges best scores and reward flags. A known empty host save can initialize. Foreign data is left intact.

The optional positive onLike status and direct onComment with string project_id and string content, including empty image-only content, unlock Lime and Pink paint. Claims are stored and deduplicated. The same paints are earned through progression. Registration checks code 0 and releases the returned unsubscribe on exit.

The included SDK and controller suites use mock hosts. Physical handset and actual GameWave App import and real account callbacks remain unverified.
