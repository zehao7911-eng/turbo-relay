# Turbo Relay 3D

Tap the screen to start and tap again to transfer power between two rocket bots. Raised green gates are clear. Tap when a red gate approaches. Both bots wait automatically if both routes are blocked, and the final bot times its own gates. Dock both to finish. A collision costs a fuse. Three stars require a clean finish within par.

Six authored circuits, best scores, unlockable paint and local pause/resume. The single top-right control opens pause or settings. Space also switches power. Escape pauses.

The 3D waterfront, moving gate arms, hover robots and effects are built from original procedural geometry. Three.js is bundled locally under MIT. The original 168 BPM drum-and-bass track starts on the first tap and can be muted in Settings. Both index.html and standalone.html embed the engine, artwork and audio code. A browser with WebGL is required.

Build with node build.cjs. Tests are tests.mjs, art-tests.mjs, sdk-tests.mjs and controller-tests.mjs. Modular entry: index-source.html.

References for this update: GameWave River Mill and Skydiving share previews for 3D depth, bright outdoor scenery and minimal touch controls. The relay gameplay and assets are original. This update uses the existing turbo-relay-v1 local save key and the same GameWave profile envelope.
